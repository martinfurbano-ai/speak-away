# Bring your own key

**Planned. None of this is in the Speak Away app today.**

This design proposes optional providers for transcription, polish and summaries. The provider list and settings below are proposals, not setup instructions for the released app.

| Proposed provider | Website | Proposed use |
|---|---|---|
| Groq | [console.groq.com](https://console.groq.com) | Transcription and summaries |
| OpenAI | [platform.openai.com](https://platform.openai.com) | Transcription and summaries |
| Anthropic | [console.anthropic.com](https://console.anthropic.com) | Summaries |
| OpenRouter | [openrouter.ai](https://openrouter.ai) | Summaries |
| ElevenLabs | [elevenlabs.io](https://elevenlabs.io) | Transcription |
| Ollama | [ollama.com](https://ollama.com) | Local summaries |

Proposed flow: **Settings → Keys**, pick the provider, paste, **Test**. Keychain storage is planned, not implemented.

Spanish design: [es/llaves-api.md](es/llaves-api.md). Planned ChatGPT and Claude integration: [connect-chatgpt.md](connect-chatgpt.md).
